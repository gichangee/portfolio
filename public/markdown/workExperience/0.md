# 하림 디지털혁신팀

### 가금 WMS 운영 및 고도화

* **24시간 무중단 CI/CD 파이프라인 구축:** Jenkins와 IIS(ARR) 기반 롤링 업데이트 아키텍처를 설계하여, 배포 시 발생하는 다운타임(Downtime)을 Zero화하고 데이터 수신 누락 리스크 원천 차단
* **대용량 데이터 인터페이스 쿼리 성능 최적화:** 지연 프로시저 로그 분석으로 암시적 형변환(`NVARCHAR` → `VARCHAR`)에 의한 인덱스 풀스캔 병목을 도출 및 튜닝하여 송수신 시간 단축 및 연관 화면 조회 속도 대폭 향상
* **웹 서버 아키텍처 리팩토링 및 레거시 개선:** 기존 IIS `WFASTCGI` 모듈을 `Waitress` WSGI 서버로 마이그레이션하여 안정성을 확보하고, Nexus(사내망 패키지 관리) 도입 및 보안 취약 변수(`.env`) 분리 수행
* **비즈니스 로직 시각화를 통한 커뮤니케이션 효율화:** 복잡한 가금 물류 흐름(입출고, 재고 이동)을 직관적으로 도식화한 가이드 문서를 기획/제작하여, 도메인 이해도 격차 해소 및 기능 개선 리드타임 단축과 CS 문의 건수 감소

---

### Tech Stack

* **Backend / DB:** Python, Django, Oracle
* **DevOps / Infra:** Jenkins, IIS, Waitress, Nexus
